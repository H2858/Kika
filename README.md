# Glassly Widgets (ويدجتات زجاجية)

Native Android (Kotlin + Jetpack Compose + RemoteViews). minSdk 26, targetSdk 35.

## Build
1. Open this folder in Android Studio (Ladybug or newer, JDK 17).
2. Let Gradle sync (it downloads Gradle 8.9 from gradle-wrapper.properties).
3. Run on a device, or Build > Generate Signed Bundle / APK for release.

## Widgets
Glass Clock (12h / 24h / system), Glass Calendar, Glass Battery (ring), Glass Quick Settings, Glass Quote & Notes.
Every widget: glass color, opacity, corner radius, border, text color. Reconfigure by long-pressing the widget.
